# Web

React + Vite + TypeScript, no UI library. Talks to the bank API (default `http://localhost:8000`; set
`VITE_API_URL` to change it).

```sh
npm install
npm run dev      # http://localhost:5173  (#customer, #staff)
npm run build    # type-check + production build
```

See [`bank/README.md`](../bank/README.md) for the API and how to run everything.
