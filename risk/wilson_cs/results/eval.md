## Caveats

- Synthetic data. The generator and the risk agent were written to the same contract, so flags that mirror the harm definition (credit without verification or lookup) will look strong here; treat absolute numbers as a ceiling, not a forecast.
- Thresholds come from normal validation sessions only (good agents, legit customers). The review rule (severity >= 0.8) means every issue_credit is at least a review, which can by itself use up the 25% log budget; see calibration_per_seed in eval.json.
- Agent-level AUC is computed over only about six agents per seed, so it is coarse.
